# MyGo 客户端（迁移中）

这里是 Go 1.27.3 + MyGo 原生界面的新客户端，未使用 WebView。目前包含 SSH 主机指纹确认、密码/私钥连接、多会话终端、本机连接列表、文件操作和云同步原型。可同时打开最多 12 个本机或 SSH 终端，每个会话保留独立的文件位置、排序和点文件显示状态，文件列表优先显示并支持独立滚动，可按名称、大小和修改时间排序；支持一次拖入最多 100 个普通文件，显示进度和成功失败数量并支持取消，已存在的目标不会被覆盖，可同时分屏查看两个会话，点击终端会切换当前会话，文件面板标明所属会话；本机会话可浏览和复制本机文件，文件和目录可通过右键选择后重命名，删除需确认且不递归。本机重命名不会覆盖已有目标；远程重命名前检查目标是否存在，并发写入时防覆盖仍取决于 SFTP 服务端实现。本机连接列表保存地址、收藏和最近成功连接时间等元数据，不保存 SSH 密码或私钥口令；用户应通过可信渠道核对主机指纹并验证功能。

在仓库根目录执行 `task test` 或 `task build:client`。`task build:client` 通过固定版本 MyGo 打包客户端及 libghostty-vt 动态库；该任务暂不生成安装程序。

文件面板可定位到终端目录，也可选择跟随 shell 报告的目录变化；Windows 本机 PowerShell 会自动报告文件系统目录，同时保留已有提示符；远程 shell 需要输出 OSC 7 工作目录信息，未报告时会提示。手工浏览不会被旧目录反复覆盖。

SSH 或本机终端结束后，标签会显示断开或退出状态，文件操作暂停；SSH 可在原标签中重新连接，重连仍在发送凭据前核验已信任的主机指纹。旧转发不会自动恢复。

SSH 工作区支持本机端口转发：只监听 `127.0.0.1`，通过已验证主机密钥的当前 SSH 会话连接远程目标；可手动停止，会话结束时自动停止。每个会话最多 8 条转发，每条最多 64 个并发连接。

终端字号可通过侧栏按钮或终端内 Ctrl +/−/0 调整，适用于所有已打开和新建的终端。字号、界面主题、侧栏和文件面板的显示状态保存在当前用户配置目录，重启后恢复；多窗口修改不同设置时会合并保存。

Windows 下可用 `Ctrl+Shift+1` 至 `Ctrl+Shift+4` 切换工作区，`Ctrl+Shift+T` 新建本机终端。

Windows 桌面自动化验证：`pwsh -NoProfile -File client/test-desktop.ps1 -Quiet`。它构建仅用于测试的自动化版本，在本机测试 SSH 服务上验证原生窗口与连接，不使用外部 SSH 客户端。

Windows 安装包：`task package:windows:local`。`pwsh -NoProfile -File client/install-local-windows.ps1` 要求干净且与远端一致的 `main`，执行测试并重新打包，再静默安装至 `C:\App\nekossh`，核验版本、文件哈希、开始菜单与卸载注册项；Windows 构建不带 Authenticode 签名。


本机终端使用 PowerShell 7（若安装了 PSReadLine 则加载命令语法高亮）；远程 shell 的高亮由远端配置决定。团队邀请可通过链接和密码注册或加入，邀请可撤销；平台管理员通过动态验证码执行用户、团队和加密备份管理。默认云地址为 `https://nekossh.neko233.com`，已部署并作为默认地址。写入成功后的列表刷新失败会明确提示并保留已生成的邀请链接；连接列表可能过期时需刷新后再修改。

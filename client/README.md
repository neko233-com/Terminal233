# MyGo 客户端（迁移中）

这里是 Go 1.27.3 + MyGo 原生界面的新客户端，未使用 WebView。目前包含 SSH 主机指纹确认、密码/私钥连接、多会话终端、本机连接列表、文件操作和云同步原型。可同时打开最多 12 个本机或 SSH 终端，每个会话保留独立的文件位置、排序和点文件显示状态，文件列表优先显示并支持独立滚动，可按名称、大小和修改时间排序；支持一次拖入或通过原生选择器多选最多 100 个普通文件，确认选择后开始传输，还可多选最多 100 个普通文件批量下载或本机复制，显示进度、成功失败数量和逐文件失败详情并支持取消，已存在的目标不会被覆盖，可同时分屏查看两个会话，点击终端会切换当前会话，文件面板标明所属会话；本机会话可浏览和复制本机文件，文件和目录可通过右键选择后重命名，删除需确认且不递归。本机重命名不会覆盖已有目标；远程重命名前检查目标是否存在，并发写入时防覆盖仍取决于 SFTP 服务端实现。本机连接自动保存地址、收藏和最近成功连接时间等信息；Windows 通过当前用户的 DPAPI 加密保存 SSH 密码和私钥口令。用户应通过可信渠道核对主机指纹；当前账户下的恶意程序仍可能读取本机凭据。

在仓库根目录执行 `task test` 或 `task build:client`。`task build:client` 通过固定版本 MyGo 打包客户端及 libghostty-vt 动态库；该任务暂不生成安装程序。构建工具会校验固定版本的 MyGo 源码，在 `build/` 的临时副本中加入终端输入钩子并在完成后清理；不会修改模块缓存。请使用 Taskfile 构建和测试客户端：直接调用 Go 构建不会包含广播输入支持。

连接中心支持保存本机空分组和多级分组，展开或折叠层级，创建子分组、重命名或确认移除分组；移除时连接及子分组移到上级，名称冲突时不会合并。可将本机连接拖到分组，也可通过编辑连接设置分组。保存显式分组时至少使用版本 2 存储格式，包含加密凭据时使用版本 3；旧版客户端会拒绝读取和覆盖新格式，避免丢失数据；展开状态仅保存在当前窗口。连接中心还可分别勾选多个本机或当前云端空间的连接，或一次勾选当前筛选结果，批量创建副本或确认后批量移除。筛选隐藏的已勾选项仍会参与操作并在界面标明；本机副本不保存密码或私钥口令，多窗口写入冲突时不会应用批量更改。云端批量操作逐条执行，支持取消（等待当前请求结束），已确认的操作不会回滚；遇到错误或冲突立即停止并提示已确认的数量，需刷新核对。旧版服务没有并发删除保护时会提示风险。切换空间或刷新云端列表会清除云端勾选。

连接中心顶部可搜索或快速连接，下方以卡片展示分组、本机终端和 SSH 连接；列表滚动时搜索与工具栏保持可见。侧栏的“连接筛选”可展开收藏、最近连接和分组树。宽窗口中单击主机可在右侧编辑详情，同时保留主机列表；新建主机时地址框自动获得焦点。切换主机、分组或通过新标签页打开连接时，完整的本机编辑会立即保存；保存失败、未完成或未同步的云端编辑会留在表单中。详情标题固定在顶部，连接与云同步操作固定在底部；保存和手动获取指纹可从标题的更多操作展开，自动保存失败时也会显示。未使用的私钥选项默认收起，已配置私钥时会提示优先使用私钥。双击进入连接流程，右键管理，来源筛选、排序及批量选择入口收在“更多操作”中。点击“连接”会先获取未知主机的指纹，核对后再次确认；本机已信任的主机仍在 SSH 握手中验证指纹，云端指纹不会自动成为本机信任。可点击分组卡片进入下一级或将主机拖入分组。详情未保存时，关闭编辑器需再次确认；较窄窗口使用全宽编辑器。支持云端服务的个人和团队空间各自保存多级分组及空分组；团队成员只读，管理员和所有者可管理。分组或连接被其他设备修改时需刷新后重试；分组过期时连接中心直接提供刷新入口，已被移除的分组不会继续隐藏连接。旧版服务没有该功能，客户端不会伪造同步分组。

文件工作区在宽窗口提供两个独立目录面板：左侧可搜索并选择本机、已打开的 SSH 会话、本机保存的主机或当前云空间的主机，右侧使用当前终端会话（本机或 SSH）；目录、选择和历史相互独立。路径与导航控件排在同一行，文件列表随窗口高度扩大。两侧可选择本机或云端保存的主机，经正常主机密钥验证后连接；从左侧打开新主机时保留右侧当前会话与目录，失败后可重试，离开连接流程则取消本次面板切换。可选择普通文件或目录使用按钮、右键或在两栏之间拖放；两个远程会话之间直接流式传输，不创建本机暂存文件。目录复制会先检查整棵目录，最多 10000 项、32 层，不支持符号链接或特殊文件。目标已存在时不会覆盖；目录复制中断后会保留已创建的部分内容并提示，单文件取消会尝试清理未完成目标。SFTP 不能完全防止其他进程在检查与写入之间替换目标路径。左侧面板可按名称筛选、新建目录、重命名，以及确认后删除文件或空目录；重命名不会主动覆盖现有目标。修改或切换目录时未完成的操作会失效；更改筛选条件会清除该面板的选择，避免误操作。两栏均可用 Ctrl 或 Shift 多选最多 100 个文件和目录，通过按钮、右键或拖放批量复制；逐项显示成功、失败及未处理数量，支持取消并报告保留的部分目录。系统文件可拖到右侧会话面板。两栏均为单击选择、双击进入目录，双击普通文件可用外部编辑器打开，也可使用右键菜单；本机文件右键可复制路径或上传到当前会话，远程普通文件可右键直接复制到本机面板的当前目录。会话列表的筛选和排序控件按需展开，上传、复制、重命名等工具可通过“文件操作”展开。较窄窗口可切换本机与会话面板。每个会话的目录支持独立后退与前进（最多保留 100 个已成功打开的目录），也可定位到终端目录或选择跟随 shell 报告的目录变化。Windows 本机 PowerShell 会自动报告文件系统目录，同时保留已有提示符；远程 shell 需要输出 OSC 7 工作目录信息，未报告时会提示。手工浏览不会被旧目录反复覆盖。


文件外部编辑默认使用 Windows 记事本，可在设置中选择其他编辑器。远程文件下载为当前用户受限访问的临时副本（不超过 16 MiB），编辑器保存后自动检测并上传；编辑任务显示主机、目录、状态和本机副本路径，可停止监控或在错误后重新尝试。关闭任务或应用不会删除副本，设置中可复制临时文件夹位置，副本位于 `nekossh-edit-` 开头的目录中，可在确认无用后手动清理。上传前核对远程内容、权限和属主，冲突时停止并保留副本；服务器需支持 OpenSSH 的原子重命名扩展。原子替换保留常规权限和属主，但可能改变 ACL、扩展属性和硬链接；SFTP 不提供原子条件写入，因此检查与替换之间仍可能发生并发覆盖。特殊权限文件、符号链接和超过大小限制的文件不能使用此功能。

宽窗口将已打开的会话标签固定在顶部，可在主机列表和各个终端之间直接切换，并支持拖动或右键调整会话顺序；窄窗口在终端页显示标签。已打开的终端默认收起导航侧栏，可通过顶部菜单临时展开，返回其他工作区后恢复原有侧栏设置。终端工具栏以图标提供查找、命令片段、分屏、文件和服务器状态，悬停可查看名称，键盘与辅助技术可使用中文标签。SSH 或本机终端结束后，标签会显示断开或退出状态，文件操作暂停；SSH 可在原标签中重新连接，重连仍在发送凭据前核验已信任的主机指纹。旧转发不会自动恢复。

新标签页直接显示已保存的工作区模板；可从主机列表进入多选模式，搜索并选择本机终端和已保存主机，一次打开为工作区。选择会跨搜索保留，回车选择当前结果，Esc 清空搜索或退出选择；也可在工作区管理中选择现有终端并组成一个工作区标签。聚焦视图在侧栏切换会话，分屏视图同时显示工作区的全部终端（最多 12 个），可拖动分隔线及终端标题调整尺寸和顺序。可添加已打开的会话或新建本机终端，右键成员可移出而不关闭，右键标签可重命名或解散，关闭整个工作区需要再次确认。工作区工具栏可开启广播输入，将用户键盘、输入法文本和粘贴发送到同一工作区的所有活动终端；工具栏会持续显示目标数量。每个终端按自身模式编码按键和粘贴，终端协议应答不会广播。成员增减、重新连接或目标不可用时广播关闭，且默认关闭。工作区可将当前会话、活动标签、视图、分屏尺寸和文件面板目录保存为本机模板，再一起恢复。保存视图时模板文件升级为版本 2，旧客户端会拒绝读取以免覆盖。模板只包含主机引用和本机已核对的指纹，不保存 SSH 密码或私钥口令；本机 SSH 主机需先保存凭据，云主机需登录原云账号并拥有各空间的访问权限。恢复会逐个重新验证指纹；任一连接失败或取消时，本次创建的会话全部关闭，原有会话保留。本机和远程终端可记录 shell 通过 OSC 7 报告的工作目录；远程目录与文件面板目录分别保存，并在聚焦和分屏视图显示。远程恢复使用已验证的 SSH 主机密钥和 POSIX shell，目录以字面量传入；无法进入目录时终端会提示并保留默认目录。远程主机需支持执行 /bin/sh，恢复后的交互 shell 不保证加载登录配置。保存含远程目录的模板时格式升级为版本 3，旧版客户端会拒绝读取和覆盖。未报告目录的远程会话会在保存时提示；运行中的命令目前不会自动恢复。模板当前保存在本机，不随云同步。

顶部加号或 Ctrl+T 打开新标签页，可搜索已打开的会话、本机和当前云空间的已保存主机，或输入 SSH 地址进入连接表单，也可打开本机终端。搜索支持多个关键词及 `用户@主机`；上下方向键选择结果，回车打开，Esc 先清空搜索再关闭标签页。新标签页可暂时切换到其他会话并返回；未保存的主机详情不会被另一主机覆盖。

SSH 工作区支持本机端口转发：只监听 `127.0.0.1`，通过已验证主机密钥的当前 SSH 会话连接远程目标；可手动停止，会话结束时自动停止。每个会话最多 8 条转发，每条最多 64 个并发连接。

普通用户可将当前个人或团队空间的密码连接导出为独立密码保护的 `.nekobackup` 文件（scrypt + AES-GCM），并在有写入权限的空间追加导入。支持分组的服务会同时备份云端分组；导入会合并同名分组，旧服务不能导入含分组的新版备份。备份包含 SSH 密码和主机指纹，不包含私钥；不得遗失备份密码。导入不会覆盖已有连接，但可能产生重复；可取消导入，取消须等待当前请求结束，已成功写入的连接保留；失败或请求未确认时需刷新核对。

侧栏“命令片段”可在没有终端会话时管理命令和多行脚本；选中片段后可编辑、删除，或向当前终端发送并回车，双击片段打开编辑器。可新建、重命名或移除分组，在编辑片段时选择分组，并按分组筛选；移除分组会保留其中的片段。多窗口修改冲突时需刷新重试。单行命令也可插入；多行脚本可复制，直接插入可能会在不支持括号粘贴的终端中执行。发送会与输入行中已有内容一起执行，并切回目标终端。选中片段后可选择多个已打开的本机或 SSH 会话，再向所选终端发送并回车；会话编号用于区分同名目标。发送前会检查所有目标和片段是否仍有效，提交不代表远程命令已经完成。该操作不等同于实时键盘广播。脚本请使用空格缩进。宽窗口中也可在终端右侧打开快速命令列表：单击选择并显示操作，双击运行，右键编辑或删除；Ctrl+. 可开关面板。命令和分组仅保存在本机明文文件，不参与云同步，请勿保存密码或令牌。使用分组后存储文件升级为版本 3，旧版客户端会拒绝读取和修改，避免覆盖分组数据。

片段工作区的分组卡片可进入分组或接收拖放；可开启“选择片段”勾选多个片段后一起拖动，也可通过选择目标并点击“移动”完成操作。筛选隐藏的已勾选片段仍会参与移动，界面显示总数；目标分组或任何所选片段被其他窗口修改时，整个移动会取消，刷新后可重新选择。

窄窗口或较矮窗口中，快速命令和文件面板采用紧凑可滚动布局，为终端保留空间；较矮窗口中的双终端改为左右排列。

终端查找可搜索当前屏幕和滚动历史、查看匹配数量并跳转；每个会话独立保留查找状态，关闭查找会清除高亮。可点击“查找”或按 Ctrl+Shift+F 打开。匹配对 ASCII 字母不区分大小写。

终端字号可通过顶部设置或终端内 Ctrl +/−/0 调整；设置中还可选择跟随界面、Catppuccin、Dracula 或 Nord 终端配色，调整分屏布局、面板尺寸及查看快捷键和更新。跟随界面时终端前景与背景使用当前工作区的浅色或深色配色，命令颜色仍由终端调色板和 shell 输出决定。字号和配色适用于所有已打开和新建的终端。字号、界面主题、侧栏和文件面板的显示状态保存在当前用户配置目录，重启后恢复；多窗口修改不同设置时会合并保存。

Windows 下可用 `Ctrl+Shift+1` 至 `Ctrl+Shift+4` 切换工作区，`Ctrl+Shift+T` 新建本机终端。拖动终端或文件面板分隔线后，可在侧栏保存面板尺寸；也可恢复默认尺寸。尺寸保存在当前用户配置中并在重启后恢复。

Windows 原生 OLE 批量拖放验证：`task test:desktop:drop`，使用 MyGo 的原生拖放测试钩子和临时文件，不需要操作真实用户文件。

Windows 桌面自动化验证：`pwsh -NoProfile -File client/test-desktop.ps1 -Quiet`。它构建仅用于测试的自动化版本，在本机测试 SSH 服务上验证原生窗口与连接，并通过隔离的 HTTPS 同步服务验证加密连接备份、邀请、成员角色和多团队切换；不使用外部 SSH 客户端。

Windows 安装包：`task package:windows:local`。`pwsh -NoProfile -File client/install-local-windows.ps1` 要求干净且与远端一致的 `main`，执行测试并重新打包，再静默安装至 `C:\App\nekossh`，核验版本、文件哈希、开始菜单与卸载注册项；Windows 构建不带 Authenticode 签名。


本机终端使用 PowerShell 7（若安装了 PSReadLine 则加载命令语法高亮）；远程 shell 的高亮由远端配置决定。团队邀请可通过链接和密码注册或加入，邀请可撤销；邀请链接指向当前同步服务，接收方须将链接粘贴到 NekoSSH，自部署地址可显式选用，服务不匹配时不会发送邀请或密码；成员可直接选择，所有者可管理成员，管理员和所有者可管理邀请及团队连接，普通成员为只读；角色未知时需刷新团队列表；平台管理员通过动态验证码执行用户、团队和加密备份管理。默认云地址为 `https://nekossh.neko233.com`，已部署并作为默认地址。写入成功后的列表刷新失败会明确提示并保留已生成的邀请链接；连接列表可能过期时需刷新后再修改。服务能力探测失败时暂停更新或删除已有连接，刷新云端连接会重试探测；确认不支持并发保护的旧服务仍可使用，但会显示风险提示。切换团队时，连接列表加载成功但成员列表加载失败会保留可用连接并显示错误；连接列表加载失败则保留原空间。只有明确载入或由当前表单、会话成功创建的记录会被更新；每个同步空间分别记住服务端返回的记录编号，不再按相同主机、端口和用户名自动覆盖。首次复制到另一空间会新建记录。

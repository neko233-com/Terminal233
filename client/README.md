# MyGo 客户端（迁移中）

这里是 Go 1.27.3 + MyGo 原生界面的新客户端，未使用 WebView。目前包含 SSH 主机指纹确认、密码/私钥连接、多会话终端、本机连接列表、文件操作和云同步原型。可同时打开最多 12 个本机或 SSH 终端，每个会话保留独立的文件位置、排序和点文件显示状态，文件列表优先显示并支持独立滚动，可按名称、大小和修改时间排序；支持一次拖入或通过原生选择器多选最多 100 个普通文件，确认选择后开始传输，还可多选最多 100 个普通文件批量下载或本机复制，显示进度、成功失败数量和逐文件失败详情并支持取消，已存在的目标不会被覆盖，可同时分屏查看两个会话，点击终端会切换当前会话，文件面板标明所属会话；本机会话可浏览和复制本机文件，文件和目录可通过右键选择后重命名，删除需确认且不递归。本机重命名不会覆盖已有目标；远程重命名前检查目标是否存在，并发写入时防覆盖仍取决于 SFTP 服务端实现。本机连接列表保存地址、收藏和最近成功连接时间等元数据，不保存 SSH 密码或私钥口令；用户应通过可信渠道核对主机指纹并验证功能。

在仓库根目录执行 `task test` 或 `task build:client`。`task build:client` 通过固定版本 MyGo 打包客户端及 libghostty-vt 动态库；该任务暂不生成安装程序。

连接中心支持保存本机空分组和多级分组，展开或折叠层级，创建子分组、重命名或确认移除分组；移除时连接及子分组移到上级，名称冲突时不会合并。可将本机连接拖到分组，也可通过编辑连接设置分组。保存显式分组时使用版本 2 存储格式，旧版客户端会拒绝读取和覆盖该文件，避免丢失空分组；展开状态仅保存在当前窗口。连接中心还可分别勾选多个本机或当前云端空间的连接，或一次勾选当前筛选结果，批量创建副本或确认后批量移除。筛选隐藏的已勾选项仍会参与操作并在界面标明；本机副本不保存密码或私钥口令，多窗口写入冲突时不会应用批量更改。云端批量操作逐条执行，支持取消（等待当前请求结束），已确认的操作不会回滚；遇到错误或冲突立即停止并提示已确认的数量，需刷新核对。旧版服务没有并发删除保护时会提示风险。切换空间或刷新云端列表会清除云端勾选。

分组管理和终端设置可按需展开；窄窗口中的排序及批量选择入口收在“更多连接操作”中。支持云端服务的个人和团队空间各自保存多级分组及空分组；团队成员只读，管理员和所有者可管理。分组或连接被其他设备修改时需刷新后重试。旧版服务没有该功能，客户端不会伪造同步分组。

文件面板支持每个会话独立的目录后退与前进（最多保留 100 个已成功打开的目录），也可定位到终端目录或选择跟随 shell 报告的目录变化；Windows 本机 PowerShell 会自动报告文件系统目录，同时保留已有提示符；远程 shell 需要输出 OSC 7 工作目录信息，未报告时会提示。手工浏览不会被旧目录反复覆盖。

SSH 或本机终端结束后，标签会显示断开或退出状态，文件操作暂停；SSH 可在原标签中重新连接，重连仍在发送凭据前核验已信任的主机指纹。旧转发不会自动恢复。

SSH 工作区支持本机端口转发：只监听 `127.0.0.1`，通过已验证主机密钥的当前 SSH 会话连接远程目标；可手动停止，会话结束时自动停止。每个会话最多 8 条转发，每条最多 64 个并发连接。

普通用户可将当前个人或团队空间的密码连接导出为独立密码保护的 `.nekobackup` 文件（scrypt + AES-GCM），并在有写入权限的空间追加导入。支持分组的服务会同时备份云端分组；导入会合并同名分组，旧服务不能导入含分组的新版备份。备份包含 SSH 密码和主机指纹，不包含私钥；不得遗失备份密码。导入不会覆盖已有连接，但可能产生重复；可取消导入，取消须等待当前请求结束，已成功写入的连接保留；失败或请求未确认时需刷新核对。

快速命令可保存、搜索、编辑和删除单行命令，支持插入当前终端或发送并回车；与输入行中已有内容一起执行。命令仅保存在本机明文文件，不参与云同步，请勿保存密码或令牌。

窄窗口或较矮窗口中，快速命令和文件面板采用紧凑可滚动布局，为终端保留空间；较矮窗口中的双终端改为左右排列。

终端查找可搜索当前屏幕和滚动历史、查看匹配数量并跳转；每个会话独立保留查找状态，关闭查找会清除高亮。可点击“查找”或按 Ctrl+Shift+F 打开。匹配对 ASCII 字母不区分大小写。

终端字号可通过侧栏按钮或终端内 Ctrl +/−/0 调整；侧栏还可选择跟随界面、Catppuccin、Dracula 或 Nord 终端配色。字号和配色适用于所有已打开和新建的终端。字号、界面主题、侧栏和文件面板的显示状态保存在当前用户配置目录，重启后恢复；多窗口修改不同设置时会合并保存。

Windows 下可用 `Ctrl+Shift+1` 至 `Ctrl+Shift+4` 切换工作区，`Ctrl+Shift+T` 新建本机终端。拖动终端或文件面板分隔线后，可在侧栏保存面板尺寸；也可恢复默认尺寸。尺寸保存在当前用户配置中并在重启后恢复。

Windows 原生 OLE 批量拖放验证：`task test:desktop:drop`，使用 MyGo 的原生拖放测试钩子和临时文件，不需要操作真实用户文件。

Windows 桌面自动化验证：`pwsh -NoProfile -File client/test-desktop.ps1 -Quiet`。它构建仅用于测试的自动化版本，在本机测试 SSH 服务上验证原生窗口与连接，并通过隔离的 HTTPS 同步服务验证加密连接备份、邀请、成员角色和多团队切换；不使用外部 SSH 客户端。

Windows 安装包：`task package:windows:local`。`pwsh -NoProfile -File client/install-local-windows.ps1` 要求干净且与远端一致的 `main`，执行测试并重新打包，再静默安装至 `C:\App\nekossh`，核验版本、文件哈希、开始菜单与卸载注册项；Windows 构建不带 Authenticode 签名。


本机终端使用 PowerShell 7（若安装了 PSReadLine 则加载命令语法高亮）；远程 shell 的高亮由远端配置决定。团队邀请可通过链接和密码注册或加入，邀请可撤销；邀请链接指向当前同步服务，接收方须将链接粘贴到 NekoSSH，自部署地址可显式选用，服务不匹配时不会发送邀请或密码；成员可直接选择，所有者可管理成员，管理员和所有者可管理邀请及团队连接，普通成员为只读；角色未知时需刷新团队列表；平台管理员通过动态验证码执行用户、团队和加密备份管理。默认云地址为 `https://nekossh.neko233.com`，已部署并作为默认地址。写入成功后的列表刷新失败会明确提示并保留已生成的邀请链接；连接列表可能过期时需刷新后再修改。服务能力探测失败时暂停更新或删除已有连接，刷新云端连接会重试探测；确认不支持并发保护的旧服务仍可使用，但会显示风险提示。切换团队时，连接列表加载成功但成员列表加载失败会保留可用连接并显示错误；连接列表加载失败则保留原空间。只有明确载入或由当前表单、会话成功创建的记录会被更新；每个同步空间分别记住服务端返回的记录编号，不再按相同主机、端口和用户名自动覆盖。首次复制到另一空间会新建记录。

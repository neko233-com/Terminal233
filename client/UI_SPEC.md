# Windows 原生界面规范

## SFTP 工作区

- 使用两个平等的文件面板；左侧默认为本机，右侧默认为所选主机。面板间可拖动分隔线调整宽度，窄窗口切换显示单侧面板。
- 每个面板从上到下依次为来源与操作、目录导航、列标题、可滚动文件列表和状态栏。目录路径保持可编辑；后退、前进、上级目录和刷新使用一致的轻量图标按钮。
- 文件图标、名称和元数据与列标题对齐；名称优先占据可用空间，宽度不足时隐藏修改时间，长名称截断并保留提示。
- 空闲时只显示与当前上下文有关的操作；选择文件后才显示相关复制操作，删除仍需明确确认。支持拖拽文件及目录、右键菜单、多选、键盘操作和可访问标签。
- 无连接时显示居中的图标、简短说明和明确的主机连接入口；操作失败、断线及传输状态必须保留可读提示，不得因精简界面而隐藏。
- 使用一致的深浅主题颜色和克制的边框；字体、间距、控件大小随 Windows 缩放与窗口尺寸保持可读，避免装饰性动画。

该规范描述目标交互和布局约束，不代表所有窗口尺寸、输入设备和缩放比例都已完成验证。

## 串口终端

- 从新标签页进入串口连接，参数提供明确标签和可读错误；连接前可刷新端口列表，也可手动输入 COM 端口。初始 DTR/RTS 状态由用户明确选择，RTS/CTS 流控启用时由驱动控制 RTS。
- 串口终端使用普通会话标签、分屏和关闭流程；断开后保留输出并提供重新连接。串口不是本机 shell 或 SSH 文件会话，不应出现可操作的会话文件面板。
- 本机工作区可保存串口参数。设备路径属于本机，跨设备同步遇到串口会明确提示，不静默转换为本机 shell。

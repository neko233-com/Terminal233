# Go 同步服务

默认客户端地址为 `https://nekossh.neko233.com`。服务尚未完成独立安全评估，暂不用于高价值凭据；自部署前需确认 DNS、Cloudflare 和源站配置。

账号可加入多个团队，每个团队最多 1000 名成员。团队所有者可邀请成员、设置管理员、移除成员；所有者和团队管理员可管理团队 SSH 凭据和邀请，普通成员可读取共享凭据。邀请具有独立密码、有效期、使用次数和撤销能力；新用户可以直接通过邀请注册。邀请链接中的令牌放在 URL 片段，不随 HTTP 请求发送；应通过另一安全渠道单独传递邀请密码。

服务 0.3.4 起，`/healthz` 的 `capabilities` 包含 `conditional-account-update`。更新已有连接时，客户端可提交上次读取的 `updatedAt` 作为 `expectedUpdatedAt`；服务会在写入锁内比较，不一致时返回 HTTP 409 和 `account_conflict`。此能力对个人和团队连接均适用；为兼容旧客户端，不提交条件时仍允许覆盖，因此不能防止旧客户端覆盖其他设备的更改。当前桌面客户端尚未使用该条件，正式使用前还需完成客户端接入并升级线上服务。

自部署时设置 `TERMINAL233_PUBLIC_URL` 为此服务的公开 HTTPS 地址（例如 `https://sync.example.com`，如使用路径前缀也需包含）。邀请响应将使用该地址生成链接，绝不信任请求中的 Host 或转发头；未设置时只返回邀请令牌，旧客户端需要设置后才能收到完整链接。新版客户端可根据当前服务地址生成链接。

数据存放在 SQLite 中，数据库中的应用数据以 AES-GCM 加密；用户和邀请密码经 scrypt 哈希。旧版本加密文件首次启动时会迁移，原文件保留为 `.legacy-backup`；请先备份并在升级前停止旧服务。该实现整份加密状态上限为 16 MiB，服务以文件锁阻止多个实例同时打开同一数据库，并在检测到外部修改时拒绝访问和写入。备份使用同一服务主密钥加密，仅能在配置了相同主密钥的服务上恢复。恢复会替换全部数据并使所有会话失效；管理员需在客户端明确确认。

公网部署必须使用专用服务账户，并通过受信任的 HTTPS 反向代理或 Cloudflare Tunnel 将流量引向默认回环监听端口。注册及认证限制、环境变量、管理员引导和威胁边界见 [SECURITY.md](SECURITY.md)。客户端内的服务器管理区可由指定管理员查看、启停用户或团队，并导出和恢复加密备份；普通用户没有这些权限。

## Cloudflare Tunnel 模板

`deploy/cloudflared.yml.example` 是单用途隧道配置模板，不包含凭据。需要专用、持续在线的源站，先在该主机运行并核验 Go 服务及 SQLite 备份，再创建或选择专用于本服务的 Cloudflare Tunnel，填入真实 UUID 与私有凭据文件，配置 `nekossh.neko233.com` 的 DNS 路由。不要覆盖其他业务的现有隧道配置。配置域名前应检查现存记录及证书状态；启用后从公网检查 HTTPS、注册、登录、团队隔离和限流，并完成重启恢复及备份恢复演练。

当已有通配符 DNS 指向 Cloudflare 时，也可用 `deploy/edge-worker.mjs` 配合专用 Tunnel 和 Workers VPC，将精确域名路由至回环服务，而不修改共享网关。该 Worker 是 Cloudflare 平台的 JavaScript 传输适配器；业务服务仍为 Go。配置 VPC 服务和 `ALLOWED_HOST` 后，必须按安全文档设置独立 HMAC 密钥，并检查 Worker 路由优先级、来源认证、限流和端到端可用性。Worker 测试使用 `task test:edge`（需要 Node.js）。

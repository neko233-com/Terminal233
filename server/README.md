# Go 同步服务（迁移中）

本目录的 Go 实现处于迁移和安全验证阶段，已接入 MyGo 客户端原型，完整端到端验证尚未完成，暂不用于生产。旧 Node 文件暂时保留以支持迁移前的产品入口。

服务只允许绑定回环 IP；公开部署必须由受信任的 HTTPS 反向代理终止 TLS。`TERMINAL233_MASTER_KEY` 和 `TERMINAL233_OFFICIAL_TOKEN` 必须分别设置为独立的至少 32 字符随机值，数据路径可由 `TERMINAL233_DATA_PATH` 配置。口令在服务端以 AES-GCM 加密存储；服务端持有主密钥，因此这不是端到端加密，服务端或密钥泄露会暴露凭据。需要完成安全评估、备份恢复、客户端集成和生产部署验证后才能投入使用。

新接口要求同步条目携带客户端已核对的 SHA256 主机指纹；服务端不连接用户指定的 SSH 目标，避免由同步接口发起任意网络访问。管理员网页已从新实现移除。限流依据直接连接地址，不信任可由请求者伪造的转发头；通过单一代理部署时所有用户共享来源限流，生产部署需要代理侧限流。

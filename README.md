# NekoSSH

NekoSSH 是使用 Go 1.27 与 MyGo 原生界面构建的 SSH 桌面客户端，配套自部署凭据同步服务。客户端无需 WebView 或外部 SSH 客户端。当前 Windows 程序和快捷方式仍使用 `Terminal233` 名称，以兼容现有安装。

- `client/`：MyGo 原生客户端、进程内 SSH、PTY、SFTP 与同步客户端。
- `server/`：Go 凭据同步服务，不转发 SSH 会话或主动连接用户指定的服务器。
- `Taskfile.yml`：构建、测试和本机验证任务。

## 运行与验证

需要 Go 1.27.3 或更高的 1.27 版本和 [Task](https://taskfile.dev/)。MyGo 固定为 v0.7.4，其终端插件的原生库由打包器下载并校验。首次构建需要网络。

```powershell
task test                         # Go 单元测试、SSH/SFTP 测试、HTTPS 同步联调
task test:desktop:windows         # Windows 原生窗口与 SSH 连接，低优先级
task build:client                 # 构建本机 MyGo 原生程序及终端库
task package:windows:local        # 未签名 Windows 安装包
```

Windows 本机验证安装使用 `pwsh -NoProfile -File client/install-local-windows.ps1`。脚本要求 `main` 干净且与远端一致，重新运行测试和打包，静默安装到 `C:\App\nekossh`，核验版本、文件、开始菜单和卸载注册项。Windows 发布产物不带 Authenticode 签名。

客户端启动时检查本项目的 GitHub 正式发布：先验证发布清单的 SHA-256，再核对当前架构安装包的名称、大小和校验值。GitHub API 限流时，客户端会解析本项目的最新正式发布地址，并使用该发布中的 SHA256SUMS 验证清单与安装包；校验文件来自同一发布渠道，并不构成独立数字签名。用户可选择下载位置；安装包校验通过后才会放到目标路径，不覆盖已有文件，也不会自动运行。网络不可用时不影响本地使用。

客户端支持密码或私钥连接，首次连接前需通过可信渠道核对 SHA256 主机指纹；云端取回的连接如指纹变化会阻止连接。连接列表支持搜索、分组、拖拽排序、右键与键盘调整；有效的本机连接在编辑后自动保存，Windows 上密码和私钥口令使用当前用户的 DPAPI 加密保存，不能从其他 Windows 用户账户解锁。加密不防止当前登录用户下的恶意程序读取凭据。云端连接需要显式同步。SFTP 支持浏览和创建目录、流式上传、单文件及多文件下载、拖入上传、取消传输和删除确认；本机路径可通过原生文件选择器填写，传输不会覆盖已有文件，取消须等待当前文件读写返回。云同步目前支持密码认证的 SSH 连接，私钥文件和私钥口令不会上传。登录同步服务后，可在连接表单中获取并核对指纹，然后直接将密码连接同步到页面显示的个人或团队空间，无需先打开终端会话。

主机可在详情面板编辑标签；主机列表和新标签页搜索均支持标签，主机卡片和“标签”菜单可按多个标签筛选，结果需匹配全部所选标签。支持标签的自建服务可同步个人或团队主机标签，并在加密备份中保留；旧服务仍可使用，但需升级后才能同步带标签的主机。

主机详情中的分组和标签输入会建议当前空间已有的选项，可用鼠标或方向键与回车选择；本机与云空间的标签建议相互隔离。云端主机可在详情中直接选择现有分组，变更受团队权限和分组版本保护。

主机列表支持 Ctrl 多选和 Shift 范围选择；把选中主机拖到分组卡片或侧栏分组即可批量移动。拖动未选中的主机只移动该主机。本机批量移动使用一次保存，云端批量移动使用一次带版本校验的更新；已选但被筛选隐藏的主机也会移动。

分组右键菜单和分组页面支持快速连接，会为该分组及子分组内的主机分别打开终端标签；单个连接失败不影响其他主机。批量连接仅使用本机已确认的主机指纹，未经确认或缺少凭据的主机会跳过并显示原因，当前同时打开的终端总数上限为 12。

终端分屏可在侧栏选择自动、左右或上下布局；设置保存在本机。自动布局会根据窗口尺寸调整，手动布局由用户决定。拖动分隔线或聚焦分隔线后按方向键可调整终端窗格大小；宽窗口中，终端与文件面板之间的分隔线也可调整。在终端工作区可拖动会话标签或通过右键菜单调整顺序，也可使用 Ctrl+Tab 和 Ctrl+Shift+Tab 切换会话。文件列表中右键普通文件可选择“下载到…”或“复制到…”，选择目标后立即开始传输，目标已存在时不会覆盖。

SSH 会话可按需打开“服务器状态”，通过独立 SSH 通道读取 Linux `/proc` 中的运行时间、1 分钟负载、内存使用量、CPU 使用率和网卡速率，并通过 `df` 读取根文件系统容量，每 5 秒刷新；速率从第二次采样开始显示，网卡合计包含虚拟网卡但不含回环接口。关闭面板、切换会话或离开终端工作区后停止读取。非 Linux 主机或禁用远程命令的服务器可能不支持此功能。

## 自部署同步服务

```powershell
task build:server
```

服务默认只监听 `127.0.0.1:8787`，公网使用必须通过 HTTPS 反向代理。配置、凭据保护、备份和威胁边界见 [server/SECURITY.md](server/SECURITY.md)。服务端持有解密密钥；这不是端到端加密。SSH 密码和账户会在服务端加密保存，不应将未完成安全评估的部署用于高价值凭据。

仓库禁用 GitHub Actions，构建与发布采用本机手工流程；未收到明确发布指令时不创建 Release 或发布 tag。

项目仓库：[neko233-com/nekossh](https://github.com/neko233-com/nekossh)。

发布资产可由 `task package:release` 在干净并已推送的 `main` 上生成，包含未签名 Windows x86_64 安装包、Linux amd64/arm64 同步服务、SHA-256 清单与源码提交清单。生成资产不会自行创建 tag 或 GitHub Release。


云同步客户端默认连接 `https://nekossh.neko233.com`。账号可加入多个团队，团队最多 1000 名成员；团队拥有者可创建带有效期、密码和次数限制的邀请，并管理角色与共享 SSH 凭据。管理员可在 MyGo 客户端管理用户、团队和加密备份。同步服务使用加密 SQLite 存储，容量及安全边界见服务端说明。

支持该功能的自建同步服务可保存个人工作区模板。登录时新保存的可移植模板会同步，已有本机模板可在管理界面手动同步，云端模板可在其他设备打开；本机路径、私钥和主机指纹不会随模板上传，目标设备须先自行确认 SSH 主机指纹。本地主机需先保存为云端连接，才能加入跨设备模板；同名或不同内容的冲突不会自动覆盖，需手动处理。本机和云端模板可分别删除。旧版同步服务仍可登录，但不提供云工作区；服务端需要更新后才可使用此功能。

在部署该默认服务的 Windows 用户账户中，若存在仅供当前用户解锁的本机注册令牌，云同步界面可通过“使用本机部署注册令牌”读取它。令牌不会随安装包发布，切换到其他服务地址时会从表单清除；其他用户需由服务管理员安全提供注册令牌，或使用团队邀请注册。

普通用户可使用独立密码加密导出当前云空间的 SSH 密码连接，并追加导入有写入权限的空间；备份不包含私钥，不会覆盖已有连接，但可能产生重复。

本机主机、身份和转发规则也可使用独立密码加密备份并追加导入；备份不包含私钥文件，导入后须重新核对主机指纹。导入过程中若客户端异常退出，下一次启动会尝试恢复；若其他程序已修改相关文件，会保留恢复数据并停止自动覆盖，可在本机导入与导出界面重试。恢复机制针对进程中断，不能保证突然断电时文件系统的持久性。

本机终端不经过 SSH；Windows 使用 PowerShell 7 和可用的 PSReadLine 显示命令语法颜色。终端支持 ANSI 色彩，远程命令行语法高亮由远端 shell 配置决定。

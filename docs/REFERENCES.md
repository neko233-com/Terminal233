# NekoSSH 参考与素材说明

## 产品与视觉研究

- [macos.kimi.site](https://macos.kimi.site/)：用于研究 Web 桌面中的窗口、Dock、菜单栏、终端等交互隐喻。
- [XTerminal](https://www.xterminal.cn/)：用于研究 SSH 工作台的连接管理、工作区与同步需求。

它们是研究输入，不是本仓库代码或素材来源。NekoSSH 不表示获得上述站点、其运营方或 Apple 的认可、授权或关联。

## 当前仓库素材状态

当前仓库没有下载、打包或复用 `macos.kimi.site` / XTerminal 的脚本、样式、图标、壁纸、截图、Apple 标识、品牌名称或其他受版权/商标保护的资源。界面应维持原创实现，使用自制图标、开放许可图标或具备明确授权的资源。

不应绕过访问控制、批量抓取站点资源，或因“参考”而默认复制页面源码。若用户拥有明确授权或资源带有适用的开放许可证，才可纳入仓库。

## 纳入第三方资源前的检查

每项外部资源都应在本文件末尾的清单中记录：

1. 资源名称、用途和仓库内路径。
2. 原始 URL、版本/下载日期和 SHA-256。
3. 许可证全文链接，或能够证明授权范围的书面记录。
4. 所需归属文案、商标限制和再分发限制。
5. 审核人及是否允许随应用打包。

许可证不明确时，默认不下载、不提交、不分发。网页截图、站点 Logo 与 Apple 品牌元素尤其需要明确授权。对生成式图片，也应记录提示词来源、生成日期和模型/工具，并避免仿冒受保护的商标或产品界面。
